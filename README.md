Before contributing, make sure to sign your 
commits by using these commands. At the end,
make sure you log into the GitHub website
and add an SSH signing key to your profile

```
gh auth login
git config --global user.name "put your name here"
git config --global user.email "put your email here"
git config --global commit.gpgsign true
git config --global user.signingkey C:\Users\(put your name here)\.ssh\id_ed25519.pub
git config --global gpg.format ssh
cat C:\Users\(put your name here)\.ssh\id_ed25519.pub
```
